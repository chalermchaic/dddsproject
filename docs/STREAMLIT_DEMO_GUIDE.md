## 1. การเตรียมเครื่องและเทคนิคจัดหน้าจอ (Screen Layout)

### 1.1 คำสั่งเปิดระบบ Streamlit:
เปิด PowerShell หรือ Terminal ในโฟลเดอร์โปรเจกต์:
```powershell
cd c:\Users\momo\dev\dddsproject
.\.venv\Scripts\activate
streamlit run app.py
```
*(เบราว์เซอร์จะเปิดหน้าเว็บขึ้นมาที่ `http://localhost:8501`)*

### 1.2 เคล็ดลับจัด 2 หน้าจอคู่กัน (Solo Presenter Trick):
เพื่อไม่ให้ต้องเสียเวลาล็อกเอาท์และล็อกอินสลับบัญชี ให้แบ่งหน้าจอเป็น **2 ฝั่งซ้าย-ขวา** (กดปุ่ม `Windows` + `ลูกศรซ้าย` และ `ลูกศรขวา`):

```
┌───────────────────────────────────────────┬───────────────────────────────────────────┐
│          ฝั่งซ้าย: ระบบ CRM พนักงาน          │          ฝั่งขวา: Customer Portal         │
│          (หน้าต่างเบราว์เซอร์ปกติ)           │     (หน้าต่างไม่ระบุตัวตน / Incognito)     │
│             http://localhost:8501         │             http://localhost:8501         │
├───────────────────────────────────────────┼───────────────────────────────────────────┤
│ • ล็อกอิน: marketing1, sale1, cs1, admin1 │ • คลิกปุ่ม: 🌐 เข้าเป็นผู้สนใจ/ลูกค้า     │
│ • ทำหน้าที่: จัดการหลังบ้าน, ออกบิล, AI   │ • ทำหน้าที่: ลงทะเบียน, โอนเงิน, ให้ 5 ดาว │
└───────────────────────────────────────────┴───────────────────────────────────────────┘
```
> **ข้อดี:** Session ของทั้ง 2 หน้าต่างแยกขาดจากกัน คุณสามารถคลิกส่งจากฝั่งขวา แล้วหันมาคลิกรับเรื่องฝั่งซ้ายได้ทันทีแบบ Real-time โดยไม่ต้องรีเฟรชหน้าจอ!

## 3. ขั้นตอนการคลิกและบทพูดทีละสเต็ป (10 นาที / 7 ขั้นตอน)

### 📦 เคสที่ 1: กระบวนการ Lead-to-Customer ด้วย AI (นาทีที่ 00:00 - 06:30)

#### [สเต็ป 1] หน้าต่างขวา (Portal ลูกค้า): ผู้สนใจภายนอกลงทะเบียน
* **การคลิก:**
  1. ไปที่แท็บ `① ลงทะเบียนขอข้อมูล`
  2. กรอกข้อมูล:
     * ชื่อ-นามสกุล: `คุณสมชาย หมายมั่น`
     * เบอร์โทร: `081-999-8888`
     * ช่องทาง: `Facebook`
  3. กดปุ่ม **"ส่งข้อมูลการติดต่อ"**
* **บทพูด:**
  > *"เราเริ่มต้นที่มุมมองของผู้สนใจภายนอก (External Entity) ใน DFD Process 1.0 ครับ เมื่อผู้สนใจเห็นสื่อโฆษณาและส่งข้อมูลผ่าน Customer Portal ข้อมูลจะถูกบันทึกเข้าสู่ Data Store D1: LEAD ทันทีครับ"*

#### [สเต็ป 2] หน้าต่างซ้าย (CRM การตลาด): ตรวจสอบ Lead และส่งโปรโมชัน
* **การคลิก:**
  1. ล็อกอินด้วยบัญชี `marketing1` (ชนิกานต์ การตลาด)
  2. สังเกตแถบเมนูด้านซ้ายจะแสดงเฉพาะสิทธิ์ของฝ่ายการตลาด (RBAC)
  3. คลิกเมนู **"งานการตลาด"**
  4. ชี้ให้เห็นว่า Lead ใหม่ (คุณสมชาย) เข้ามาแล้ว
  5. เลือกแคมเปญ **`CMP003: Digital Ads Q3`** (ส่วนลด 10%, ROI สูงสุด 103%) ➔ กดปุ่มส่งโปรโมชัน
* **บทพูด:**
  > *"ฝ่ายการตลาดใช้ระบบตรวจรับ Lead ใหม่ และเชื่อมโยงแคมเปญที่มีผลตอบแทนสูงสุด นั่นคือ CMP003 เพื่อส่งมอบโปรโมชันส่วนลดให้ผู้สนใจ เกิดการบูรณาการระหว่าง DFD 1.0 และ 5.0 ครับ"*

#### [สเต็ป 3] หน้าต่างซ้าย (CRM ฝ่ายขาย): AI Lead Scoring และออกใบเสนอราคา
* **การคลิก:**
  1. สลับล็อกอินเป็น `sale1` (ณัฐวุฒิ ขายเก่ง) ➔ เข้าเมนู **"ติดตามการขาย"**
  2. คลิกแท็บ **"🔥 คิวงาน AI (Lead Scoring)"** ➔ ชี้ให้ดูกลุ่ม Hot Lead รหัส **`LD0264` (นายวิชัย ทองดี)** ได้คะแนน **85%**
  3. สลับไปแท็บ **"🔍 ค้นหา & บันทึกกิจกรรม"** ➔ เลือกรหัส `LD0264` ➔ บันทึกช่องทาง `โทรศัพท์` ➔ โน้ตว่า *"ลูกค้าสนใจแพ็กเกจ Cloud ERP ตกลงรับข้อเสนอ"* ➔ กด **"บันทึกกิจกรรม"**
  4. คลิกเมนู **"คำสั่งซื้อ & บิล"** ➔ แท็บ **"📝 ออกใบเสนอราคา"** ➔ เลือกรหัส `LD0264`
  5. เลือกสินค้า `PRD001: Cloud ERP Suite` จำนวน `1` ชุด (สังเกตระบบดึงส่วนลดแคมเปญมาหักลดอัตโนมัติ) ➔ กดปุ่ม **"บันทึกใบเสนอราคา"** (ได้รหัสเอกสาร SL)
* **บทพูด:**
  > *"ฝ่ายขายไม่ต้องสุ่มโทรครับ โมเดล Random Forest คัดกรองคิวงานให้เห็นว่าคุณวิชัย LD0264 มีโอกาสปิดการขายสูงถึง 85% พนักงานจึงโทรติดต่อและออกใบเสนอราคาตาม DFD Process 2.0 พร้อมคำนวณส่วนลดอัตโนมัติครับ"*

#### [สเต็ป 4] หน้าต่างขวา (Portal ลูกค้า): ยืนยันคำสั่งซื้อและแนบสลิป
* **การคลิก:**
  1. สลับมาหน้าต่างขวา เลือกรหัสผู้สนใจ `LD0264`
  2. คลิกแท็บ **"③ ยืนยันคำสั่งซื้อ"** ➔ กดปุ่มยืนยัน
  3. คลิกแท็บ **"④ อัปโหลดสลิปการโอนเงิน"** ➔ กดปุ่มแนบสลิปจำลอง (หรือเลือกไฟล์สลิป)
* **บทพูด:**
  > *"ลูกค้าตรวจใบเสนอราคา กดยืนยันคำสั่งซื้อ และแนบสลิปโอนเงินผ่านระบบ Self-service ข้อมูลจะไหลเข้าสู่ DFD Process 3.1 และ 3.2 ครับ"*

#### [สเต็ป 5] หน้าต่างซ้าย (CRM ฝ่ายขาย): ตรวจรับเงินและยกระดับเป็น CUSTOMER
* **การคลิก:**
  1. สลับมาหน้าต่างซ้าย อยู่ที่เมนู **"คำสั่งซื้อ & บิล"**
  2. คลิกแท็บ **"💳 ตรวจสอบการชำระเงิน"** ➔ เห็นภาพสลิปที่ลูกค้าส่งมา ➔ กดปุ่ม **"ยืนยันรับเงินถูกต้อง"**
  3. คลิกแท็บ **"🧾 ออกใบเสร็จ + บันทึกลูกค้า"** ➔ กดปุ่ม **"ออกใบเสร็จ"**
  4. ชี้ให้เห็นว่าระบบได้ทำการ Insert ข้อมูลเข้าสู่ตาราง `CUSTOMER` (รหัส CU) สำเร็จเรียบร้อย
* **บทพูด:**
  > *"เมื่อฝ่ายขายตรวจรับเงิน ระบบจะอัปเดตสถานะเป็น 'ปิดการขายสำเร็จ' พร้อมยกระดับจากสถานะ Lead ให้กลายเป็น CUSTOMER ในฐานข้อมูล 3NF ทันที และออกใบเสร็จรับเงินตาม DFD Process 3.3 ครับ"*
